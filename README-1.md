## 🗂️ Projects

### 1. 🎨 Personal Portfolio Website
A responsive personal portfolio built with semantic HTML5 and CSS3 — no frameworks, no JavaScript.

- **Technology:** HTML5, CSS3 (Flexbox, Grid, media queries)
- **Key features:**
  - Semantic structure (`header`, `nav`, `main`, `section`, `footer`)
  - About, Education, Projects, and Contact sections
  - Fully responsive across desktop, tablet, and mobile
- **Folder:** [`Assignment-1-Personal-Portfolio/`](./Assignment-1-Personal-Portfolio)
- **Live demo:** [View Live](PASTE_PORTFOLIO_VERCEL_URL_HERE)

### 2. ⚛️ React Components Practice
Five reusable React components demonstrating core React fundamentals.

- **Technology:** React + Vite
- **Key features:**
  - `Header`, `Footer`, `Card`, `Button`, and `Form` components
  - Props-driven, data-independent components (e.g. the same `Button` is reused with different labels/handlers)
  - Local component state (`useState`) demonstrated in `Card` and `Form`
  - Controlled form inputs with `onChange`/`onSubmit` events
  - Multiple cards rendered dynamically from an array via `.map()`
- **Folder:** [`Assignment-2-React-Components/`](./Assignment-2-React-Components)
- **Live demo:** [View Live](PASTE_REACT_COMPONENTS_VERCEL_URL_HERE)

### 3. 📰 React Blog UI (Mini Project)
A small blog layout rendering post cards from a JSON data file, with live search and category filtering.

- **Technology:** React + Vite
- **Key features:**
  - Post cards rendered dynamically from a JSON file via `.map()`
  - Live, case-insensitive search across post titles and excerpts
  - Category filter with options derived directly from the post data
  - Search and category filter work together (combined conditions)
  - Clear empty state when no posts match
  - Responsive card grid (CSS Grid + Flexbox)
- **Folder:** [`Mini-Project-React-Blog-UI/`](./Mini-Project-React-Blog-UI)
- **Live demo:** [View Live](PASTE_REACT_BLOG_VERCEL_URL_HERE)

## 🎯 Learning Outcomes

Through these three projects, this week focused on:

- Semantic HTML5 structure and accessible markup
- Responsive layout design with Flexbox and CSS Grid
- Breaking a UI into small, reusable React components
- Passing data between components with **props**
- Managing changing data within a component using **state**
- Handling user interaction with React **events** (`onClick`, `onChange`, `onSubmit`)
- Rendering dynamic lists of data with `.map()`
- Building simple **search** and **filter** functionality driven by component state
